# ตารางราคาและเงื่อนไขเสนอขาย

## ระบบสั่งอาหารและบริหารร้านอาหาร DEMO Bang saen

**วันที่จัดทำ:** 6 พฤศจิกายน 2569  
**สถานะ:** ราคาเสนอเบื้องต้นสำหรับซอฟต์แวร์สำเร็จรูปตาม [TOR](TOR.md) เมื่อระบบผ่าน UAT แล้ว; repository ปัจจุบันยังไม่ใช่หลักฐานว่าระบบ Hono/D1 เสร็จแล้ว  
**หน่วยเงิน:** บาทไทย ราคาต่อไปนี้ยังไม่รวม VAT หากผู้ขายมีหน้าที่เรียกเก็บ

## 2. ที่มาของราคา

ราคาเป็น **ราคาขายผลิตภัณฑ์ที่พัฒนาเสร็จแล้วสำหรับร้าน 1 แห่ง** ไม่ใช่ราคาจ้างพัฒนาระบบใหม่ 50 ฟังก์ชันตั้งแต่ต้น ผู้ขายยังถือสิทธิ์ในซอฟต์แวร์ต้นฉบับและสามารถให้สิทธิ์รายอื่นได้ตามเงื่อนไขสัญญา จึงเฉลี่ยต้นทุนพัฒนาของผลิตภัณฑ์และคิดราคาเฉพาะสิทธิ์ใช้ การติดตั้ง การดูแล และเวลาปรับแก้ตามแพ็กเกจ

| ส่วนประกอบราคาแบบซื้อครั้งเดียว                         |  จำนวนเงิน |
| ------------------------------------------------------- | ---------: |
| สิทธิ์ใช้งานถาวรสำหรับร้าน 1 แห่งพร้อมสำเนา source code |     30,000 |
| ตั้งค่าบัญชี/ติดตั้งทางไกล/ตรวจรับ                      |      6,000 |
| คู่มือและอบรมออนไลน์ 2 ครั้ง                            |      3,000 |
| **รวม**                                                 | **39,000** |

| ส่วนประกอบราคาแบบรายเดือน         | จำนวนเงิน/เดือน |
| --------------------------------- | --------------: |
| สิทธิ์ใช้และดูแลบริการขั้นพื้นฐาน |           1,400 |
| เวลาปรับแก้ 4 ชั่วโมง × 500 บาท   |           2,000 |

อัตรา **500 บาท/ชั่วโมง** เป็นอัตราเสนอของผู้ขายในเอกสารนี้ ไม่ใช่อัตรากลางราชการ หากใช้แรงงาน Fullstack คนเดียว งานปรับแก้ที่รวม 4 ชั่วโมงต่อเดือนคือครึ่งวันทำงานโดยประมาณ ไม่ใช่งานไม่จำกัดปริมาณ

## 4. ตัวอย่าง VAT และการชำระ

หากผู้ขายมีหน้าที่เรียกเก็บ VAT ให้ใช้อัตราที่มีผล ณ วันออกใบกำกับภาษี ตัวอย่าง ณ วันที่จัดทำเอกสารใช้อัตรา **7%** ตาม [กรมสรรพากร](https://rd.go.th/59.html)

| รายการ             | ก่อน VAT | VAT 7% |    รวม VAT |
| ------------------ | -------: | -----: | ---------: |
| ซื้อครั้งเดียว     |   39,000 |  2,730 | **41,730** |
| รายเดือน 1 เดือน   |    3,900 |    273 |  **4,173** |
| รายเดือน 12 เดือน  |   46,800 |  3,276 | **50,076** |
| งานเพิ่ม 1 ชั่วโมง |      500 |     35 |    **535** |

หากผู้ขายไม่มีหน้าที่เรียกเก็บ VAT **ไม่บวก VAT ตามตารางตัวอย่าง** แบบซื้อครั้งเดียวแบ่งชำระสองงวด งวดละ **19,500 บาทก่อน VAT**: งวดแรกเมื่อทำสัญญา งวดสุดท้ายหลังผ่าน UAT และส่ง source code แบบรายเดือนชำระล่วงหน้ารายเดือน

## 5. ขอบเขตการปรับแก้และค่าใช้จ่ายอื่น

| ประเด็น                                     | ซื้อครั้งเดียว                      | รายเดือน                                                                      |
| ------------------------------------------- | ----------------------------------- | ----------------------------------------------------------------------------- |
| Defect ที่ไม่ตรง TOR                        | แก้ฟรี 30 วันหลังตรวจรับ            | แก้ตลอดสัญญาตามลำดับความรุนแรง                                                |
| ปรับข้อความ หน้าจอ หรือกฎธุรกิจในขอบเขตเดิม | 500 บาท/ชั่วโมง ขั้นต่ำ 2 ชั่วโมง   | ใช้เวลารวม 4 ชั่วโมง/เดือน ไม่คิดต่อคำขอ                                      |
| งานเกินเวลาที่รวม                           | แจ้งประมาณการและอนุมัติก่อนทำ       | เข้าคิวเดือนถัดไป หรือเร่งด่วน 500 บาท/ชั่วโมงเมื่ออนุมัติ                    |
| ฟังก์ชันใหม่/เชื่อมระบบอื่น                 | ประเมินราคาแยก                      | ประเมินราคาแยก                                                                |
| Source code                                 | ส่งหลังชำระครบ ใช้แก้ไขภายในร้านได้ | ไม่ส่ง สิทธิ์ใช้สิ้นสุดเมื่อสัญญาสิ้นสุด                                      |
| Cloudflare และ domain                       | ผู้ซื้อชำระตามจริงกับผู้ให้บริการ   | รวมค่า Cloudflare 500 บาท/เดือน; ส่วนเกินตาม invoice เมื่ออนุมัติ; domain แยก |

คำว่า **“ปรับแก้ได้ตลอด”** หมายถึงส่งคำขอและจัดลำดับงานได้ตลอดอายุสัญญา ไม่ใช่รับประกันงานไม่จำกัดชั่วโมงหรือเสร็จทันทีทุกคำขอ ความเร็วการทำงานขึ้นกับคิวและความซับซ้อน

## 6. ค่าบริการ Cloudflare

ค่า Workers, D1 และ R2 คิดตามบัญชีและปริมาณใช้งานจริง จึงไม่อ้างว่าค่าใช้จ่ายจะเท่ากับ 500 บาททุกเดือน หากแบบรายเดือนเกินวงเงิน 500 บาท ผู้ขายต้องแจ้งหลักฐานและขออนุมัติก่อนเรียกเก็บส่วนเกิน แบบซื้อครั้งเดียวผู้ซื้อชำระตรงตามจริง

ตรวจราคาและขีดจำกัดล่าสุดจาก [Workers](https://developers.cloudflare.com/workers/platform/pricing/), [D1](https://developers.cloudflare.com/d1/platform/pricing/) และ [R2](https://developers.cloudflare.com/r2/pricing/) ก่อนทำสัญญา ค่า Cloudflare เป็นค่าโครงสร้างพื้นฐานของผู้ให้บริการ ไม่ใช่ค่าลิขสิทธิ์รายเดือนที่ซ่อนอยู่ในราคา

## 7. ข้อสรุปสำหรับเสนอขาย

- ผู้ซื้อที่ต้องการ source code และดูแลระบบเอง: **39,000 บาทครั้งเดียว** แล้วจ่ายเฉพาะงานแก้/เพิ่มตามที่อนุมัติ
- ผู้ซื้อที่ต้องการให้ผู้ขายดูแลและปรับงานย่อยต่อเนื่อง: **3,900 บาทต่อเดือน** ขั้นต่ำ 12 เดือน พร้อมเวลาปรับแก้ 4 ชั่วโมงต่อเดือน

**ข้อมูลที่ต้องกรอกก่อนออกใบเสนอราคาอย่างเป็นทางการ:** ชื่อคู่สัญญา/สาขา สถานะ VAT domain เจ้าของบัญชี Cloudflare วันเริ่มบริการ ช่องทางแจ้งเหตุ และผู้ลงนาม UAT
